1. Protocol & Response Envelope

All API responses use UTF-8 JSON formatting wrapped inside a standard response envelope containing execution status, human-readable feedback, and the payload entity.

// Standard JSON Envelope
{
  "success": true,
  "message": "Operation completed successfully.",
  "data": { ... }
}
GET /api/campus/health-index

Computes the comprehensive Campus Environmental Health Index (CEHI) score (0–100 scale), letter grade (A+ to F), and sub-index scores for AQI, IAQ ventilation (CO2), acoustic noise, and thermal comfort.

Query Parameters: zone_id (integer, optional)
GET /api/analytics/radar

Returns normalized 5-axis environmental scores (Air Cleanliness, Acoustic Quietness, IAQ Ventilation, Thermal Comfort, Particle Safety) for all 8 campus geographic zones for spider / radar visualizations.

GET /api/analytics/correlations

Calculates the pairwise Pearson correlation coefficient matrix between Temperature, Humidity, PM2.5, PM10, CO2, Noise, and AQI across recent campus observations.

GET /api/readings

Fetch historical time-series environmental records with optional filtering by zone_id, sensor_id, start_date, end_date, and limit.

GET /api/readings/latest

Fetches the most recent environmental reading for each of the campus zones.

POST /api/readings/simulate-pulse

Generates a realistic telemetry reading, stores it in SQLite, and triggers the automated threshold alert evaluation engine immediately.

GET /api/zones

Retrieve all configured campus geographic zones, their descriptive metadata, and active sensor counts.

GET /api/sensors

List all hardware sensor stations, their physical zones, model types, operational status, and last communication timestamps.

GET /api/alerts/active

Retrieve all unresolved environmental safety threshold alerts across all campus zones.

GET /api/reports/summary?period=daily

Generate statistical summaries across daily, weekly, or monthly periods with aggregate mean, min, max, and violation frequencies.
